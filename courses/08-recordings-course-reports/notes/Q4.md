# Q4 — Report structure: overview → per-learner drill-down → export

**Coverage:** Circle partial (overview and sampled export; no drill-down transition) · Kajabi partial (learner detail only) · SchoolAI partial (overview and sampled export; no learner-detail transition) · Uxcel partial (overview with drill-down affordance only).

**Circle.** The course dashboard presents course-level student count, average completion rate, and engagement tabs for Students, Comments, and Quiz results (`mobbin:3a9baed1-2367-4a3b-9c61-6f0c792fb0ee`). The separate flow begins on a draft dashboard, then samples a published dashboard with a student table (name, progress, last active, start date), an overflow menu containing “Export comments,” “Export students,” and “Export quiz results,” and finally an email-delivery confirmation toast (`mobbin:464a297d-2355-443d-8123-d61f80c4a72c`). The intervening publish/navigation, export selection click, email, and resulting file are unobserved; no student row is opened.

**Kajabi.** A breadcrumb places the screen at Analytics / Product Progress / Prototyping 101 / Jane Doe. It is already a per-learner detail: 50% overall progress, last activity, module progress, and lesson-level complete/not-complete status (`mobbin:1227af09-4d68-457a-a7ea-a5596e2c3e4f`). The overview-to-Jane transition and export are absent from this capture. This is the clearest detail hierarchy, but completion evidence should not be read as assessed mastery.

**SchoolAI.** One session report combines class mastery, outcome distributions, step progress, a searchable learner list, generated session insights, and named student insights (`mobbin:00828d09-252c-4d02-92a1-58966ebbe19d`). Its download flow samples a pre-insight state with “Generate session insights,” a generated state exposing “Download CSV,” and a success toast after download (`mobbin:82be552c-140b-4a19-95bb-037c320ca775`). The generation wait/click, CSV click, and file are unobserved. Learner insights sit in the overview; no separate learner drill-down is shown. Unlike Circle/Kajabi’s completion-oriented views, SchoolAI explicitly reports outcomes/mastery.

**Uxcel.** Reporting shows organization/member context, assignment and unit-completion summaries, and activity with “View report” (`mobbin:87f9d574-30e4-4053-80c3-4d4cc189ca69`). The button suggests drill-down, but its destination and export are unobserved.

For course management, the evidence favors an overview that keeps cohort status visible, opens a learner/course-item detail, and exports from the same reporting context. **Candidate counter-example:** Circle’s export flow: useful proximity, but its initial draft state and omitted click make the claimed overview-to-export sequence discontinuous.

**Best references:** `mobbin:82be552c-140b-4a19-95bb-037c320ca775` for the strongest report-to-export endpoint; `mobbin:1227af09-4d68-457a-a7ea-a5596e2c3e4f` for the clearest learner drill-down anatomy.

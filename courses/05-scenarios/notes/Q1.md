# Q1 — Library browse: search, filters, preview

## Comparison

Figma is the strongest reusable-library model. `refero:flow-5039` keeps an Assets search field, library cards, an **All libraries** menu with individual library toggles, and grid/list controls in one panel; the final frame shows an asset placed on the canvas. `refero:screen-2e0d5f12` adds the missing inspection layer: selecting a component opens a Details popover with a large preview, description, provenance, variable-mode choice, and **Insert instance**.

Canva (`refero:flow-8062`) is strongest for preview-before-commit: three suggested designs remain beside a large live canvas, color variants update that preview, and **Use Canva Editor** is the continuation. It does not show keyword search, metadata filters, or course insertion.

MasterClass (`mobbin:666b7eaa-84c1-4d32-a152-9b6ae3ae9eb9`) shows learner discovery rather than author reuse. The visible sequence is: recommendation card with **Play / My List** → Library → horizontal category chips, Search, Filters/Clear filters, and lesson rows labeled with class/category. It supplies a useful compact mobile browse pattern, but no preview-to-add course action.

## Course-specific counterexample

Teachable (`refero:flow-9573`) starts at an empty Courses table with Filter/Search and **Create course**, then walks through a 5-step creation wizard (metadata/media and pricing are visible). This creates a new course rather than finding a reusable scenario, so it is evidence of the detour an Essentials library should avoid.

## Reuse recommendation

Combine Figma’s searchable library and details/insert split with Canva’s persistent large preview. Borrow MasterClass’s compact category chips and result metadata for mobile. Keep **Add to course** available only from the inspected scenario, and expose scenario-specific filters such as tags, competency, and duration; none of the five references demonstrates all three.

# Q1 — Objectives are structured (list items, not free text) and reorderable

**Verdict: structured is observed; reorderable is unverified.**

Teachable’s Course setup → Custom Checkout Content presents “Bullet Points” as individually labelled fields, plus **Add a Bullet Point** and per-item delete controls. This is clear list-item authoring rather than one rich-text block. A second state shows populated and empty items in the same repeated structure. Neither screen exposes a drag handle, move arrows, or another reorder control, so Teachable only partially satisfies the combined question. [mobbin:007d841f-48d2-425f-bbaf-75ba21693a3c; mobbin:fbde5f46-53c8-464f-8ff5-a4bca072426a]

Udemy’s Plan your course → Intended learners step asks “What will students learn in your course?” and requires at least four learning objectives/outcomes. Each response has its own field and character counter, followed by **Add more to your response**. This is the strongest course-objective evidence, and the learner-facing “What you’ll learn” checklist corroborates that outcomes are treated as discrete statements. Again, no reorder affordance is visible. [mobbin:3558619c-01e4-44de-9e1b-159104717ba1; mobbin:04a7c094-adec-42d4-9f50-b4500ed8825d; mobbin:d3ce7d30-a5b0-4586-9312-62fb4365aa18]

The Udemy Curriculum screen is a different pattern: one learning-objective field belongs to a section, alongside controls for sections and curriculum items. It should not be used to claim that the course-level objective list is reorderable, because any visible hierarchy is curriculum-unit structure rather than objective-item structure. [mobbin:7fa8a407-5fc0-4de1-b169-0c7825495e47]

**Candidate counterexample:** Teachable shows a bounded repeated list (“up to five bullet points”) with add/delete but no visible reorder control. This challenges reorderability as a default, although a static screen cannot prove reordering is impossible. [mobbin:007d841f-48d2-425f-bbaf-75ba21693a3c]

**Gap:** no supplied evidence demonstrates an objective being dragged, moved, or saved in a changed order. There is also no Semester → Courses management screen tying either pattern to that exact information architecture.

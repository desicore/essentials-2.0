# Q4 — Objectives can be linked downstream (lesson, assessment, competency)

**Verdict: yes for section-level curriculum association; yes as a cross-domain analogue for explicit downstream linkage; assessment and competency linkage remain unproven.**

Udemy provides the closest course-native evidence. In `mobbin:7fa8a407-5fc0-4de1-b169-0c7825495e47`, the curriculum editor asks, “What will students be able to do at the end of this section?” The learning-objective field sits inside Section 1, directly above its nested lecture and `+ Content` control. This establishes a local objective-to-section association and places lesson/content authoring beneath it. The same screen says sections can contain lectures and practice activities including quizzes, coding exercises, and assignments, but it does not show an objective explicitly mapped to an individual lesson, assessment, or competency.

Asana demonstrates the generic downstream-linking interaction as an **analogue**, not proof of course integration. The sampled preview sequence in `mobbin:2f67fe8d-dbad-4ee4-ad75-5d08c69fe948` is: goal page with “No projects connected” and `Connect a project` → searchable project picker showing “Design Project” → goal page showing `1 connected project`, a project row, weight, and progress. The distinctive behavior is an explicit relationship that lets project work automatically update goal progress. `mobbin:497f13ae-8101-487c-9bc2-477b6effce96` shows a populated goal dashboard, while `mobbin:2435925c-c007-4f9d-a529-32bdc976aa68` shows goal metadata and “No sub-goals connected”; neither standalone image independently proves supporting-work linkage.

`refero:957512a1-de88-42af-9586-1a9e3b1a1a0c` is a Linear marketing hero (“Plan and navigate from idea to launch”). No initiative-to-project relation is visible, so it cannot support Q4.

**Product comparison:** Udemy embeds the objective in the curriculum hierarchy; Asana makes the relationship an explicit attach/search/confirm flow with roll-up semantics. No image demonstrates reusable competency mapping or objective-level assessment alignment.

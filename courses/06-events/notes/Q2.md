# Q2 — Linking content and groups to the event, and directionality

**Google Classroom** (`refero:20c8ba7c-4cf4-4afe-ac52-cf3f62712cf2`): image shows only an "Add link" dialog on the class stream, no event/content/group linkage visible. No usable evidence for this question.

**HubSpot** (`mobbin:0135db7d-6118-4df0-b8eb-645026ef853f`): event detail panel has collapsible "Associated campaign" and "Lists" sections, both empty in this shot. Shows the field *exists* for event→content and event→group links, but no populated data and no reverse view (campaign/list page showing the event back). Direction: event→content/group only, inferred not confirmed.

**Luma** (`mobbin:787e8052-f653-4151-9df7-924b5726d087`): Invite Stats panel lists individual invitees (e.g. "Alex Smith") with accept/decline status from inside the event. This is event→people, but people are individual invitees, not a learner-group object. Direction: event→attendee only, one screen.

**Peloton** (`mobbin:399ec1b5-4c98-4b27-b3d8-eae1ecc148ce`): a browsable class schedule with category filters (Strength, Meditation). Category filtering is not the same as an event being linked to specific content/group; this is a list view, not an event-detail link. Weak/off-topic evidence.

**Preply** (`refero:9226`, flow): lesson entry is tied to one tutor/subject; reschedule flow (list → "…" menu → Reschedule → pick new slot) never surfaces content selection or a group — the lesson is inherently 1:1. **Counter-example candidate**: illustrates a product with essentially no content/group linking step at all.

**Rise** (`mobbin:1caacacf-3691-435b-8ac4-5f6a1f0e8b42`): calendar event side panel shows "2 participants" with avatars and "Add participant or room," i.e. event→people, individuals again rather than a group entity. Only the event-side view is shown.

**Understory** (`refero:12719`, flow, 4 frames inspected): Calendar → "+ Event" → **"Select the experience" modal** (radio-pick one of several existing Experiences) → event form pre-fills the experience title, then exposes Capacity, Location, Resources, "+Rooms/+Guides/+Details." This is the clearest explicit **content→event** link step at creation. Direction shown: content chosen when creating the event (content→event); no reverse view (an Experience page listing its scheduled events) is in these frames — evidence gap. No group/cohort field appears; "Guides" and "Rooms" are resources, not learner groups.

**Workable** (`mobbin:da2ca788-e66b-44ba-8008-7659ccc746a3`): "Create event" panel opened from a candidate profile, title auto-populated "Call with Cindy Jung - UI/UX Designer." Shows content/record→event context at creation; reverse (event shown on candidate's own timeline) plausible but not in frame.

# Q3 — Shareable link controls (expiry, access level, revoke, tracking)

## Per product

- **ClickUp** `mobbin:7f248abd-f90a-4477-a2a7-8b9aa0cbcc10` — Public tab of share sheet: public link + Preview, "Expire link after: Never" (no presets visible), search-engine toggle, per-field visibility toggles (Assignee, Priority, Due date, Description), red Unpublish button as the only revoke path. No view/comment/edit access level and no tracking.
- **Coda** `mobbin:c333ff8e-e76b-44a7-ba91-3f29d4dfbd7f` — doc view → open Share → link row with "No access"/"Can edit" dropdowns for link/workspace tiers + Copy link → type name → set per-person level "Can edit" + note + Notify toggle → Send → confirmation toast with person now listed "Can edit / Hasn't signed up" → Embed tab (iframe, play/page-list toggles) → Publish tab (separate public-site step). No expiry, password, revoke, or open tracking shown.
- **Dropbox** `mobbin:777c4ef0-4481-474a-9a3c-10637247e000` — doc → Share dialog ("Anyone with this link: can edit" dropdown, Copy link, unopened Settings/Who-can-access links) → add person by email + optional note → shared confirmation → "Link copied" toast. Expiration/password screens are never actually opened.
- **Loom** `refero:1242` — video page with "0 views/No views yet" tracking placeholder → Share dialog (link-level "can view" dropdown, Spaces/people list, Share-at-timestamp checkbox, Copy link) → add person email with per-person "Can view" dropdown → confirmation shows person as "Invited, Can view" alongside Owner.
- **Mural** `mobbin:836e980f-286d-4092-a9dd-799a8ebb6bce` — single Access and Settings panel: general access (Restricted vs workspace, with Can edit level), separate visitor-link access level (Can view), password toggle (Add password), expiration date+time+timezone picker with Save/Cancel, and Reset visitor link (regenerate/revoke).
- **Notion** `mobbin:cfca14fb-a833-4bf6-b549-9e646bac5ec9` — Change access sheet: Can edit/Can comment/Can view radio, "Link expires" row opening a preset sheet (Never, In an hour, In a day, In a week — each showing resolved date/time — or Choose date), red Remove (revoke).
- **Proton** `mobbin:ef4fcd7f-0f50-47de-9df4-b67bf14bda2d` — Settings dialog: Set expiration date toggle+field, Set link password toggle+field, Stop sharing (revoke), Save changes. No access-level control shown.
- **Sketch** `mobbin:1fb17c11-dd5b-4d8c-928f-6b1b64c444fc` — doc grid context menu (Copy Link, Share…) → Share dialog with three tabs (Workspace Members-Restricted, Guests, Everyone/No Access) → Everyone tab: Can-view/Cannot-access radio plus separate Inspect-and-Download / Comment capability checkboxes for the public link. Copy Link sits top-right of the dialog throughout.

## Distinctive
- Mural `836e980f`: only one with a timezone-stamped expiration picker and a "Reset visitor link" that regenerates rather than just disables.
- Notion `cfca14fb`: only one resolving relative expiry presets to an absolute date/time inline.
- Loom `refero:1242`: only one showing open/view-count tracking tied to the share.
- Sketch `1fb17c11`: only one splitting public-link rights into separate download vs comment checkboxes instead of a single access-level control.

## Counter-example candidate
`mobbin:7f248abd-f90a-4477-a2a7-8b9aa0cbcc10` (ClickUp) — defaults to "Never" expire with no preset shown, no view/comment/edit level, no password, no tracking, and the only revoke mechanism is a global Unpublish that kills the whole public page. For a course manager sending time-boxed session materials, this offers no scoped, self-expiring, or partially-revocable link.

## Weak references
`mobbin:777c4ef0-4481-474a-9a3c-10637247e000` (Dropbox) — take claims expiration and password options are shown; none of the 5 steps actually open those settings panels, only an unclicked "Settings" link is visible.

## Take fixes
- `mobbin:7f248abd-f90a-4477-a2a7-8b9aa0cbcc10`: Public tab of iOS share sheet showing the public link, "Expire link after: Never" with no presets visible, a search-engine toggle, per-field visibility toggles, and Unpublish as the sole (all-or-nothing) revoke action.
- `mobbin:777c4ef0-4481-474a-9a3c-10637247e000`: Sharing dialog showing an access-level dropdown ("can edit"), add-person-by-email with a note, and Copy link; expiration and password settings are referenced by an unopened Settings link but not shown.
- `mobbin:1fb17c11-dd5b-4d8c-928f-6b1b64c444fc`: Flow shows three access tiers (Workspace Members, Guests, Everyone) and, for the public link, a view/no-access radio with separate Inspect-and-Download and Comment checkboxes; no recipient is actually added and no link is generated in these steps.

## Distinctive

- Superhuman `ba56c2de`: per-person, per-device, timestamped opens surfaced inline on the message thread itself (not a separate report), plus a live "is replying" indicator.
- HoneyBook `8afb0d65`: conditional branching — different follow-up email sent automatically depending on viewed/not-viewed.
- Navan `9d8af34f`: manual "Send a reminder" action triggered directly from selecting non-responders in the same status list (feedback and action co-located).
- Docusign `e4a526c1`: granular reminder cadence config (days before first reminder + repeat interval), separate from any status view.

## Counter-example candidate

Square `mobbin:1c8c3422-f935-4762-b78c-a460c688d98a` — the list has a dedicated "Seen by" column, but it shows only a dash with no populated data and no action (resend/remind). For someone managing a course, a seen-by field that never shows who saw the announcement provides no more information than a plain "Sent" status, undermining the reason to have the column.

# Q1 — Composer: audience targeting, attachment, scheduling

## Per product
- Basecamp `mobbin:25c42c82`: PDF-attached composer → clock icon → date/time dropdowns → "Schedule and save" (Drafts). No audience control.
- ClassDojo `mobbin:53e9bdad`: New post modal → attach image → AI assist (rephrase/shorten/emoji) → schedule calendar+time. Always the one open class.
- Confluence `mobbin:fcc604e7`: title+banner+emoji → Public/Private radio → optional Start/End date-time+timezone → Publish. One banner active at a time.
- Google Classroom `refero:19605564`: "For / All students" dropdown sits above the announce text box.
- LinkedIn `refero:863`: Create-post modal (Anyone visibility) → clock icon → Schedule post dialog → date expands to calendar.
- Slack `mobbin:fd356e91`: composer in open channel → send dropdown (presets/Custom) → date/time+timezone modal → Schedule. Channel/attachment unexercised.
- Teachable `refero:9617`: Send-to dropdown (individual/course/everyone) + subject/body → confirm modal → sent. Stays "All users"; no attachment.
- The Leap `refero:4564`: recipients dropdown → described segments (Contacts/Leads/Customers/Claimed product) → body → confirm → live open/click stats.
- Whop `mobbin:16eb85ed`: composer with embedded image → calendar icon → date+time popover → scheduled-state dot. No audience control.

## Distinctive
- Confluence `mobbin:fcc604e7`: only Public/Private audience radio + start/end window + one-banner cap.
- ClassDojo `mobbin:53e9bdad`: only inline AI writing-assist menu.
- The Leap `refero:4564`: only described audience segments plus post-send stats.
- Whop `mobbin:16eb85ed`: only schedule-vs-publish as one inline popover.

## Counter-example candidate
`mobbin:fcc604e7` (Confluence): "Only one announcement can be active at a time" — a manager needing a persistent materials banner plus a timely one must overwrite, not layer.

## Weak references
None.

## Take fixes
- mobbin:25c42c82: PDF-attached composer with a schedule popover — no audience/notification controls appear.
- mobbin:53e9bdad: New Post modal, photo attach, AI assist, schedule calendar — no audience selector; single class only.
- mobbin:fcc604e7: Admin banner flow, Public/Private radio (not group/individual), optional Start/End date-time — one banner max.
- mobbin:fd356e91: Scheduling via send presets or custom date/time modal — channel targeting/attachment not shown.
- refero:9617: Send-to dropdown (all/course/individual) plus subject/body, confirm modal — stays on "All users"; no attachment used.
- mobbin:16eb85ed: Inline calendar popover toggles publish vs scheduled — no audience control.

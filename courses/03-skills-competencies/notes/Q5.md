# Q5 — Learner-facing visualisation of mastery

## Evidence-backed answer

**Uxcel** is the clearest mastery model. It visibly combines a six-axis competency radar (User Research, Content Strategy, Design Leadership, Product Thinking, Visual Design, Interaction Design) with “Competency analysis,” score (59/100), reliability (40%), peer rankings, and drill-down learning resources for the selected competency. This could connect Essentials’ assessed skill/rubric results to learner reporting; how Uxcel calculates the axes is not visible. [`mobbin:c8fcc4c3-061d-4280-90d5-4600ac48bf53`]

**Codecademy** offers two different layers. The overview visibly groups named skill sets and individual skills, shows per-skill percentages, and derives an HTML & CSS level (Beginner; “Complete 5 more skills to reach Intermediate”). This is the strongest evidence of a learner-facing proficiency state. [`mobbin:41d3d178-1703-47b1-820d-b5c5348118a6`] The five-step flow is: dashboard → Skills tracking → subject/language summary → expanded catalogue → Languages filter. It shows XP bars and a “What you’ve learned to do” card, but no assessed mastery or rubric evidence; mapping XP to competence is only implied. [`mobbin:042b8064-f255-4149-9649-a2bbc057dea5`]

**Brilliant** visibly uses connected course/topic nodes, a current Level, completed/current/upcoming styling, and a Start action. The desktop detail adds lesson/exercise counts; mobile adds a streak banner. These explain sequence and current position, not assessed mastery. [`mobbin:34856cb4-4cb0-4248-ab60-d1d4bf64b665`] [`mobbin:45ede6ec-1ebd-498f-9a48-2636087f1be4`] [`mobbin:ec3fe703-fe07-489e-92a5-45eb5b3d4720`]

**Duolingo** visibly presents a linear unit path, current lesson, locked/upcoming nodes, XP reward, quests, streak/currency, and next action. It does not expose a competency score, rubric level, evidence, or mastery explanation. [`mobbin:063b737c-c4d3-4788-b91d-b137f93ebb9c`] [`mobbin:bf1baa63-a593-4155-aeb9-f027ec53355f`] [`mobbin:21f4097f-290b-438c-8f84-85f616578231`]

## Distinctiveness and curation corrections

Uxcel is multivariate and diagnostic; Codecademy is hierarchical and level-based; Brilliant and Duolingo are path-based. Candidate counterexample: Duolingo, because completion/XP/streak are engagement signals rather than assessed mastery.

Correct titles/takes: rename Brilliant refs to “Curriculum path / topic position” and state they show progression only. Rename Codecademy flow to “XP-based subject tracking flow”; drop it if Q5 requires assessed mastery. Rename all Duolingo refs to “Lesson-path progress state”; retain at most one as the counterexample and drop the duplicates.

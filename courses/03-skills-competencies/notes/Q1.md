# Q1 — Framework model: central taxonomy vs. free tags vs. both

## Evidence by product

**Coursera — model not evidenced.** The course detail page displays a fixed set of “Skills you’ll gain” labels (for example, Web Design, Ideation, User Story, Responsive Web Design, UI/UX Research) and a “View all skills” link. It shows neither authoring nor selection, and gives no evidence that instructors choose from a central taxonomy or create free tags. Distinctive evidence is the learner-facing seam between stated outcomes and catalog skill labels; no rubric, activity, scenario/event, evidence, score, or reporting connection is visible. **Corrected title:** “Course page displays ‘Skills you’ll gain’ labels.” **Corrected take:** “Catalog marketing displays skill labels, but does not evidence a governed course competency framework.” **Drop from Q1 primary evidence as unrelated to institution/ad-hoc competency selection; retain only as a candidate counterexample to treating catalog skills as governed competencies.** [`mobbin:2d300077-7580-47c6-875a-369da8b0a065`]

**Handshake — framework remains indeterminate; UI permits text entry and chip review.** One profile modal contains a single Skills field with entered text (“Principle Methods; Design Thinking”), a search icon, guidance (“What skills are you best at? We recommend 10 or less.”), and Save/Cancel. No suggestions, validation, hierarchy, or institution-owned vocabulary are visible, so “central taxonomy” is not established. [`refero:554289af-aead-4298-a222-73a19c1c1487`]

A second state shows multiple removable skill chips in the same modal and Save/Cancel. The chips demonstrate review/removal of a chosen set, but do not prove the items came from selectable suggestions: they may be free tags, controlled terms, or both. [`refero:b8e17eec-d089-4cd1-9663-63c8b65f85ac`]

Taken together, the apparent flow is: enter skill text → accumulate removable chips → save the profile. Its distinctive pattern is a compact, capped self-description workflow. It is an HR profile analogue only; neither screenshot shows course ownership, rubric levels, activity/scenario/event attachment, learner evidence, scoring, or reporting.

**Corrected titles/takes:** “Enter profile skills in a modal” / “Text entry plus Save is visible; vocabulary governance is unknown” (`refero:554289af-aead-4298-a222-73a19c1c1487`); “Review removable profile-skill chips” / “Chips evidence selected-state review, not a central taxonomy” (`refero:b8e17eec-d089-4cd1-9663-63c8b65f85ac`).

# Q6 — Reuse of the same competency set across courses and semesters

No reference proves reuse of a competency set across courses or semesters. Only Hello Ivy shows an explicit save-for-reuse action, for a document template.

## Evidence by product

**Hello Ivy — adjacent, explicit template creation.** Flow: open page → overflow menu → **Save as template** → preview, name, and choose **For everyone** or **For me only** → save → confirmation toast. This proves packaging content for reuse and exposes ownership scope. It does not show applying the template, propagation, versioning, competency identity, or cross-term reuse. Corrected take: “A page can be saved as a named personal or shared template; later instantiation and synchronization are not shown.” [`refero:4518`]

## Essentials 2.0 implication

For Semester → Courses → competencies, adapt Hello Ivy’s **name + scope + confirmation** pattern: choose source set → preview competencies/rubrics → copy into target course/semester → confirm. Clarify snapshot versus live link. Stable IDs, version lineage, historical scenario/event evidence and report scores, and behavior after template edits remain unproven.

**Candidate counterexample:** Duolingo; a shared course switcher can look like continuity while every course displays a separate XP context.

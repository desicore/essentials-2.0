Frame: https://www.figma.com/design/maOZqRuLdksiPwUA43qSVI/Essentials-2.0---wireframes?node-id=76-7251

**Verdict: good direction, then fix.** All the content is there and correct, and it's greyscale. The hierarchy is arguably stronger than 1A: NURS 310 has a dark border and a filled "Up next" badge, and it already uses outline secondary buttons with proper gaps. So the two 1A problems don't apply here. What's left is density and the chart, which was added after this run started.

## Issues, most important first

1. **The sim usage chart is missing.** It was added to the brief after 1B started, and Rule 3 says both Dashboards get the same content. There's also no room for it: the left column already reaches y≈850.
2. **There's a card inside a card, which makes it less dense than Essentials.** Every Today row and recording row is its own bordered box (about 84–92 px high) inside a bordered panel. That's twice the borders and a lot of empty vertical space. The current Essentials UI is dense (rows about 35–56 px). Flatten the rows and keep the strong border only on NURS 310. That also frees space for the chart.
3. **The date shows twice.** The Today subtitle "Tuesday, January 19 · 3 simulation events" repeats the page date. Keep only "3 simulation events". The "Rest of the week" subtitle under Upcoming isn't in the brief; remove it, as was done for the Recent recordings subtitle.
4. *Optional, not in the prompt:* the Upcoming descriptions wrap to 2 lines at 300 px. Flattening may fix this; otherwise it's fine.

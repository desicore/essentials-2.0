### B. UI library report (for engineering, 3–4 pages + appendix)

The audience is engineering, and the prototype code won't be reused, so the report answers **"should production use an external component library, and which one"**. It isn't a pitch for the prototype code.

1. **The answer first:** recommendation for the prototype, recommendation for production, and the 2–3 things engineering must check before deciding.
2. **Context:** why the question matters (the current Essentials UI is inconsistent, WCAG 2.1 AA, tablet debrief, Enterprise is Angular), and what was tested.
3. **Options:** Astryx · shadcn (+ an Angular port) · no external library, i.e. Gabor's classic track with the current design system, as the baseline.
4. **Criteria table:** one row per criterion, a 1–5 score per option, and **evidence** (a link to the frame or a log entry):
   - **Coverage:** how many of the components our 11 screens need exist in the library (from the inventory)
   - **Figma ↔ code match:** does the Figma library match the coded components (names, variants, tokens)?
   - **Theming:** how hard is it to get to the Elevate blue theme (tokens, modes)?
   - **Accessibility:** focus states, contrast, 44 px tablet targets out of the box
   - **Angular fit:** official or community Angular version, how mature, how far from the React version
   - **Build effort (measured):** minutes per screen, follow-up prompts, detached or custom-built parts
   - **AI-friendliness:** how reliably Cursor/Claude produce correct code and Figma output with it
   - **Licence, cost, maintenance:** release activity, community, vendor risk
5. **Side by side:** Dashboard and Debrief in each option (screenshots).
6. **Risks and open questions** for engineering.
7. **Appendix:** the benchmark log (one row per AI run), the component inventory, the prompts used.

**The measurement log is the backbone.** Every Cursor run appends one row: library · screen · model · start/end time · follow-up prompts · library instances vs custom frames · missing components · issues. The prompts file sets this up automatically.

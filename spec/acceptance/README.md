# Acceptance criteria

One file per cornerstone, e.g. `C1.md`. Drafted by Gabor, approved by Daniel. Each criterion is a testable "done when" statement backed by a Gleanly fact ID.

Example: *C1 is met when faculty can start a recording with a single action and no prior training (F-0123).*

The flow files already carry PRD-based "Done when" lists. These files add the evidence link.

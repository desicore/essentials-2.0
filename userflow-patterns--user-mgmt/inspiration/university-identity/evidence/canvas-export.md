For more information about report configurations, visit the [Canvas Default Account Reports resource document](https://community.instructure.com/en/kb/articles/387054-canvas-default-account-reports).

## Open Settings

In Account Navigation, click the **Settings** link.

![Account Settings tab with the Reports tab highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/GCH0S3Y79RLN/795cd72b-e879-429d-8c91-be69a64a915e.png)

## View Reports

![Reports page with the report name, help icon, and last run time highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/2TD8X0N969JA/5f0b544e-6008-4c69-9ede-4e91c5daba33.png)

The Reports page shows all available reports. Each report includes the name \[1\] and a help icon that explains more about the report \[2\]. You can also view the last time the report was run, if any \[3\].

**Note:** The Last Run report displays in the language of the user who last ran the report.

## Configure Reports

![Reports page with the Configure button highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/9B55DCWT5Y79/912d33f9-3769-4865-a53c-340c40454f66.png)

Most reports must be configured before they can be run. To configure a report, click the **Configure** button.

Depending on the report, report configurations may include one or several options.

### Select Term

![Report configuration with the Term menu and Include Deleted Objects checkbox highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/EEPVX1IBCOM3/8b0f059d-4a6b-48ac-9c7a-6ffc321c0719.png)

All reports except the LTI Report, Outcome Export, and User Access Tokens reports require you to select a term. In the **Term** drop-down menu, you can choose from the Default Term \[1\], or any active, future, or past terms. Courses with hidden assignments may not accurately reflect scores in this report.

The Grade Export, Last User Access, Student Competency, LTI Report, and User Access Tokens reports include the option to include deleted objects. Deleted objects may include deleted courses, users, or enrollments. To include deleted objects, click the **Include Deleted Objects** checkbox \[2\].

**Note:** The All Terms option is not available for the Outcome Results report; you must select a specific term.

### Select Report Order

![Outcome Results report configuration with the report order radio buttons highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/3X3VNYVLL3HN/f7f5499a-6f79-4113-9020-128033afd444.png)

The Outcome Results report allows you to choose how to order the report. Ordering options are by Users, Courses, or Outcomes. By default, the report orders by Users. Select the radio button for your preferred report order.

### Select CSV Files

![Report configuration with the CSV file, Created by SIS, and Include Deleted Objects checkboxes highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/9792I7LZAITQ/3f4bc838-81ef-4b64-a1c6-be2596c295c9.png)

The Provisioning and SIS Export reports ask you to select the CSV files you want to generate for a selected term \[1\]. Select the checkboxes next to the files you want to generate. Files can be generated for Users, Accounts, Terms, Courses, Sections, Enrollments, Groups, Group memberships, Group categories, Cross-listing (X list), User Observers, and Admins.

If you want to only view data created by your SIS, select the **Created by SIS** checkbox \[2\]. Otherwise, the CSV files display all data created in your Canvas account, including information created by SIS and through the interface.

To include concluded courses or deleted objects in the report, click the **Include Deleted Objects** checkbox \[3\].

**Note:** The selected term only impacts Courses, Sections, Enrollments (including temporary enrollments), and Cross-listing CSV files.

### Select Dates and Enrollment State

![Report configuration with the start date, end date, and enrollment state fields highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/9VIJCERKK2X2/44fd9045-20d2-446f-8bcd-aac8c9234d73.png)

The Students with no Submissions report asks you to select a start date \[1\] and end date \[2\] for the report. You can either select a date by clicking each respective date's calendar icon, or you can enter the date directly in the date field.

You may also choose to include the enrollment state in the report by clicking the **Include Enrollment State** checkbox \[3\]. In the Enrollment State drop-down menu \[4\], select all enrollments or only active enrollments.

### Select Start Date

![Report configuration with the Calendar icon and Date field highlightedReport configuration with the Enrollment Type drop-down menu highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/SI8FOEXUHOZ0/ac8c408a-710c-4070-acd3-aa9da609a117.png)

The User Course Access Log and Zero Activity reports ask you to select a start date for the report.

To select a date, click the **Calendar** icon \[1\] or enter the date in the **Date** field \[2\].

**Note:** A maximum of two years of data is retrieved in the User Course Access Log report. If a user had access to a course more than two years ago, a message appears and details are not provided.

### Select Enrollment Type

![Report configuration with the Enrollment Type drop-down menu highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/XMO53BPFZ9ST/98d429da-7d33-4f81-9336-700f44ca4a46.png)

The User Course Access Log report allows you to choose to include all or individual enrollment types. In the Enrollment Type drop-down menu, select all enrollments, student enrollments, teacher enrollments, Teaching Assistant (TA) enrollments, observer enrollments, or designer enrollments.

### Select Course Scores

![SIS Submission Report configuration with the Include course scores checkbox highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/FF2WKHHNPOOA/4865c81c-8fdf-4e5b-9168-011b8ae5caa3.png)

The SIS Submission Report allows you to include course scores. Click the **Include course scores** checkbox. By default, the SIS Submission Report does not include course scores.

**Note:** The SIS Submission Report may only display for institutions that have authenticated Canvas to post grades to their SIS.

### Filter ePortfolio Data

![ePortfolio Report configuration with the no-enrollments and removed ePortfolios checkboxes highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/SJNBQW5RRP3K/8a0860f9-0044-44fa-8f94-5ddfb84cffc4.png)

The ePortfolio Report allows you to filter the data displayed in the report.

To only display ePortfolios from users without enrollments in your Canvas account, click the **Only include ePortfolios from users with no enrollments** checkbox \[1\].

To only display removed ePortfolios, click the **Only include ePortfolios that have been removed** checkbox \[2\].

### Filter User Access Tokens

![User Access Token report configuration with the exclude and include checkboxes highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/GFB6YA4BOB13/6e2d055e-afe3-4a48-bef9-46bec29d27ef.png)

The User Access Token report allows you to filter access tokens.

To exclude deleted and expired tokens, click the **Exclude deleted and expired access tokens** checkbox \[1\]. To include tokens from deleted users, click the **Include access tokens from deleted users** checkbox \[2\].

### Run Report

![Report configuration with the Run Report button highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/HG97VTTQ3XMU/c82108d4-dc82-4a3b-aaf3-19ed3ad3d42d.png)

When you have finished configuring a report, click the **Run Report** button.

## Download Report

![Reports page with the Download icon highlighted](https://us.v-cdn.net/cdn-cgi/image/quality=80,format=auto,fit=scale-down,height=2000,width=2000/6038536/uploads/migrated/DN03OG3FSO20/339947cb-629e-4782-923c-7dc8c06a13a6.png)

When a report is complete and is available for download, click the **Download** icon. The file will download to your computer.

**Note:** When an account report fails, an error message displays with an accompanying error code.

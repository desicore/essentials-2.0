User Manager: narrowed shortlist of examples

Companion to user-manager-map-index.md. That file lists everything that touches each of Gabor's six User Manager parts. This page is the cut: the examples that best match each part, plus the examples of what not to do that belong on the "don't build this" wall.

We looked at 169 examples and kept 41, plus 10 examples of what not to do. The reasoning for each part, and every dropped example with a reason, lives in .context/user-manager-shortlist/node-*.md. Terms you will see: Learning Tools Interoperability (LTI) Names and Role Provisioning Services (NRPS) for live Canvas rosters, and a common single sign-on standard (SAML) for university sign-in.

Reports: R1: Access, roles and sharing (137 examples) · R2: University sign-in, directory sync and user import (32 examples)

Close calls dropped

Calendly's SSO, provisioning and domain-control tabs are a clean settings layout, not a flow. Pull them back if you design the settings page. Zendesk's named SAML connection and Remote SAML guide are form-level detail; GitHub's test-before-save is the stronger lesson. We also dropped WorkOS attribute toggles, Entra provisioning diagnostics, and Epidemic Sound, Maze and Workable sign-in variants. OpenAI and Miro recovery are not examples of what not to do despite the index; the shortlist data does not mark them as examples of what not to do.

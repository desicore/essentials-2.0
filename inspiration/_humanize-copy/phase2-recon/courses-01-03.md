DO NOT run (destructive / reset header): `merge-references.mjs` (01 README step 1; resets header/answers), `fetch-assets.mjs` (network; assets already local).
Generator scripts (`01/synthesise.py`, `02/write-synthesis.py`, `03/synthesise.py`) OVERWRITE references.json (+ synthesis.json / synthesis.html). I ran them on copies in tmp/gen0N: outputs are byte-identical to the committed files, so they are deterministic and currently in sync.

## KEY DECISION for the copy job: two competing sources of truth
The prose in references.json (answers, some takes/titles) and synthesis.* is WRITTEN BY the py generators from hard-coded strings. If you edit references.json / synthesis.json / synthesis.html directly and later rerun the py script, edits are lost. Options: (a) edit the JSON/HTML and never rerun generators (recommended; note in the final report), or (b) edit the py. Do not do both inconsistently. 03's generator reads references.pre-synthesis.json (not references.json), so a direct edit of references.json is overwritten by rerunning synthesise.py; 01's reads references.json (+stub + notes/Q*-verdicts.json) but reapplies hard-coded takes/answers on top.

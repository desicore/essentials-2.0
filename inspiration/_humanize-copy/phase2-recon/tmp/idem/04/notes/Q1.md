# Q1 — Group-as-unit enrolment vs. copy-at-enrol

No reference demonstrates that a course-side group attachment remains synchronized. Circle shows the closest course-specific control; Basecamp explicitly shows copy-at-use behavior.

**Circle — `mobbin:7fccd8eb-8b47-4eba-9b29-c061ef84f911`.** In “Create a course space,” the admin names the space, selects a **Space group**, and can enable **“Add members from this space group.”** This shows course-space inheritance at creation. The toggle does not say later group changes propagate; treat it as one-time inheritance unless evidenced elsewhere. Scope caveat: it creates a course space rather than attaching a group to an existing Semester → Courses record.

**Basecamp — `mobbin:03d638de-71a2-4fdd-a4a9-19fb51e82492`.** Image index **1** states that tagging a group expands everyone currently in it and that later additions/removals are **not automatically applied to previous assignments or mentions**. This is the explicit candidate counterexample: a reusable group selector snapshots current membership. It concerns group creation and general work assignment, so retain only index 1 as policy evidence, not as a course flow.

**Asana — `mobbin:bb93bc5a-69d4-4f3e-8f70-fa48fb9b6b53`.** The project-template field accepts people or teams by name. Its note says template members are added to created projects, but private teams only when the creator is a member. No team is selected or completed attachment shown; this is a picker and inheritance-policy analogy, not live-sync evidence.

**ClassDojo — `mobbin:898ffefa-af8f-45f2-a3b5-e42dcef375ad`.** Classroom → Groups → Add a group → name/select learner → Create group → group card. This is out-of-scope classroom-local group creation; it proves neither attachment nor sync.

**Teachable — `mobbin:0e3d16c1-c125-418d-91e0-2a18b696bcaa`.** Add Students uses manual rows or CSV and an optional target course before Import; no group unit or sync appears.

**Drop recommendation:** drop ClassDojo as group creation and Teachable as redundant bulk-enrolment evidence. Retain Circle as the closest course evidence, Basecamp index 1 as the counterexample, and Asana as a group-selection analogy.

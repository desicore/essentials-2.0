# Q5 — Capacity / waitlist / enrolment window handling

Podia is the only course-specific capacity/window evidence. Its course **Availability** page places **Start date** and **Sign-up limit** under Limits; the editor offers “No limit” or “Limit sign-ups” (`mobbin:ac312350-012f-49d9-9f95-25365859a6c3`). This demonstrates course-level configuration, but no cohort-size preview, over-capacity attach behavior, closing date, or waitlist.

Luma provides an event-admin analogy: **Max Capacity** accepts a numeric cap, states that registration auto-closes at capacity, and offers an **Over-Capacity Waitlist** toggle (`refero:4f821362-5e07-4f2a-9a8d-a63a3330ccdb`). This concerns event registration, not course cohort capacity.

Fresha demonstrates a booking waitlist: full date → “join the waitlist” → choose preferred date/time, optionally adding times and a day-part/range → answer first-visit question → review payment and notes → **Join the waitlist** (`mobbin:13c4d86b-b5dd-446d-8451-66c17cf96e32`). It does not prove queue order, automatic promotion, or group handling.

Deel’s course assignment step follows worker selection and offers **Assign immediately** or **Schedule assignment** for a specific date/time, plus optional **Assign with deadline**; **Assign (96)** exposes the affected count (`mobbin:eac0772e-c47f-4a3d-973c-f6a7352fe5a1`). Gusto’s course flow is select team members → set dates and reminders → review. Its due date is when learners should complete the course, automatic reminders are sent near it, a “7 days before due date” toggle and **Preview email** are shown, and overdue completion remains allowed (`mobbin:65695f4f-db86-4ab3-b40c-e2966edd2a79`). These are assignment timing and completion deadlines, not dates during which enrollment is open. Gusto is a useful counterexample to treating “due date” as an enrolment close: overdue learners may still complete.

No reference shows a learner group exceeding remaining course seats, partial admission, exception resolution, an enrolment end date, or promotion from a course waitlist. Retain Podia as the closest domain match and Luma/Fresha only as clearly labelled analogies.

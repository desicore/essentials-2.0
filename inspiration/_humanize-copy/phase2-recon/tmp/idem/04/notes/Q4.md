# Q4 — Bulk paths beside manual add

| Product | Evidence | Recommendation |
|---|---|---|
| Teachable | partial — manual + CSV course enrollment | Keep (strongest) |
| Partiful | partial — CSV invite analogy | Keep only as secondary |
| Circle | partial — export / inherited-members analogies | Drop both |

**Teachable.** `mobbin:61127de5-672c-4250-984a-73e1c0684ce1` starts in **Students**, where the empty state says owners can manually add or bulk-import students. **Add Students** opens a modal with sibling **Manually** and **Import CSV** tabs. The shown path stays manual: enter one learner → add another → enable **Enroll these students into a product** → select **Courses** and a named course → choose how access was paid → **Import** → return to Students with “successfully added” feedback. It directly demonstrates a course target and parallel CSV entry point, but never opens CSV, shows mapping/review, or proves completion of the import. No code/link or integration path appears.

**Partiful.** `refero:d19d15c3-daac-4d6e-834f-a128a511a7ba` shows one invite modal with **Add Manually / Bulk Add**, a CSV drop zone, required Name/Email headers and template download, an invitee review area, editable message, and **Send emails**. This is the clearest CSV affordance and pre-send review, but it is event invitation evidence, not LMS enrollment or continuing roster sync; delivery is not shown.

**Circle.** `mobbin:464a297d-2355-443d-8123-d61f80c4a72c` shows course dashboard → overflow menu → **Export students** → toast saying the export started and will be emailed. This is bulk data egress, the reverse of adding learners. `mobbin:7fccd8eb-8b47-4eba-9b29-c061ef84f911` shows **Create a course space**, choose a space group, and optionally inherit members from that group; it does not show manual/CSV/link/integration enrollment or confirm ongoing sync.

**Strongest evidence / counterexample.** Teachable best supports manual and CSV side by side at course enrollment. Circle export is the strongest counterexample: proximity to a course roster does not make a bulk path inbound enrollment. Drop both Circle refs as weak for Q4; retain Partiful only if an explicitly labeled invitation analogy is useful.

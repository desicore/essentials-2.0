# Q3 — Instance vs. reference semantics

**Canva — apply changes to a template instance** (`refero:flow-8062-q3`, partial; candidate counterexample). One captured state shows an AI request to increase the title’s vibrancy, three generated design choices, one outlined choice rendered on the canvas, a **Color** control, and **Use Canva Editor**. This supports a choose-then-edit handoff resembling a template copy. No source template, persistent link, before/after pair, propagation, or override behavior is visible.

**Ditto — attach text to an existing library component** (`mobbin:9d28e0e2-ba12-4eb5-9a77-c3227f36b647`, partial). The sequence is: select text → open **Library** → choose **Attach to existing component** → review the exact-match suggestion and **All components** → select `hero-title` → press **Attach** → return to the text panel, where `hero-title` appears and a toast confirms attachment. Ditto makes the instance-to-library relationship explicit at attachment time. Later propagation and per-course overrides are unverified.

**Figma — insert and configure a component instance** (`refero:flow-5040`, ✓ for linked-instance evidence). The sequence is: browse Assets libraries → open **Simple Design System** → enter **Cards** → select **Review Card** → inspect its preview and details → press **Insert instance** → choose a **Variable mode** (`Auto (SDS Light)`, `SDS Light`, or `SDS Dark`) → insert and position the card. The selected result is named **Review Card** in the design panel, with **Simple Design System** shown beneath it. This directly evidences a linked library instance plus a controlled configuration choice. Master-edit propagation and override survival are not shown.

**Notion — insert a synced block** (`mobbin:b8778e0e-13d3-49a6-9f01-3680ea66249b`, partial). The **Advanced blocks** menu lists **Synced block** alongside other block types. It makes synchronized reuse an explicit insertion choice, but the screenshot stops before insertion. Source identity, edits, propagation, and overrides remain unverified.

The references distinguish three models: linked attachment (Ditto), linked component insertion with a selectable mode (Figma), and reusable/template insertion choices (Notion and Canva). Only Figma visibly identifies the inserted instance’s source library; none demonstrates master edits propagating or per-course overrides.

# Q2 — Multi-select and batch add vs. one at a time

**Teachable — import selected lessons from another course** (`mobbin:e8676237-6e24-4e98-90a2-e37bfa82f60a`, ✓). The instructor opens **Import content**, chooses a source course, then gets a structured lesson list with row and section checkboxes plus **Select all / Select none**. After selecting multiple lessons, one **Import** action returns to Curriculum; several new lessons appear in their sections, an import toast confirms completion, and the rows remain reorderable. This is the strongest course-native precedent: source choice, visible batch scope, one commit, and destination confirmation.

**PandaDoc — add library items in a batch** (`mobbin:7833133c-7d81-4179-86a5-6ba8ce80b92c`, ✓). From the document editor, **Content Library** opens as a searchable panel with reusable block thumbnails. Multiple cards gain selected outlines; the sticky footer reports the count in **Add 2 items** and offers **Deselect all**. One action inserts both blocks into the document. It cleanly demonstrates persistent multi-selection, count-aware commitment, and immediate insertion while keeping the library open.

**Canva — copy one existing design** (`mobbin:4fb0fdd5-431c-4702-9bb5-fbcb4d78c2df`, partial). **Add new** leads to a searchable **Choose design** modal. Selecting one result enables **Copy to course** or **Move**, and the copied design appears in the ordered Activities list. It proves library reuse and copy semantics, but the single-row selection and singular action do not support batching.

**Circle and Teachable — author one question at a time** (`mobbin:327fbad0-5e87-48c9-b7cf-fb0f5bcce035`; `mobbin:8c62da99-7eb3-46dd-9610-d7d932070129`, both ✗ counterexamples). Circle opens an **Add question** modal for type, prompt, responses, and correct answer before one **Add question** commit. Teachable edits one expanded question block, adds answers inline, then exposes **New question**. Both fit original authoring, where each item needs unique content and validation. Reusing a known scenario library should instead follow Teachable import/PandaDoc: browse or search → select several → show selection count → add once → confirm inserted items in the outline.

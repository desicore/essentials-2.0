# Glossary: designer shorthand to plain words

Use the plain version. If the plain version gets clumsy in a specific sentence, pick another everyday phrase with the same meaning; never fall back to the jargon.

## UI terms

| Jargon | Plain |
|---|---|
| toast | short pop-up message |
| modal / dialog | pop-up window |
| sheet / bottom sheet | panel that slides up from the bottom |
| CTA / primary action | main button |
| affordance | visible control / visible cue |
| empty state / zero state | what the screen shows before there is any data |
| onboarding | first-time setup |
| inline | right where you are, without opening a new screen |
| chip / pill / tag | small label |
| badge | small counter or label on a button |
| drawer / side panel | panel that slides in from the side |
| sidebar | menu down the side of the screen |
| stepper / wizard | step-by-step form |
| scoped choice | choice of where it applies |
| scoped to X | limited to X |
| pre-flight check | check before you start |
| guardrail | automatic safety limit |
| granular permissions | detailed permissions |
| bulk action | do it to many items at once |
| deep link | link that opens a specific screen |
| state (success / error) | what the screen shows when it worked / failed |
| happy path | the normal case when everything works |
| counter-example | example of what not to do |
| flow | sequence of screens |
| banner | message strip across the top (or bottom) of the screen |
| toggle | on/off switch |
| segmented control | row of buttons where you pick one |
| dropdown / picker | list you choose from |
| tooltip | small hint that appears when you point at something |
| popover | small pop-up box |
| overlay | layer shown on top of the screen |
| tile / card | box on the screen (only say "card" when the product itself calls it that) |
| widget | small box on a dashboard |
| tab | tab (fine as is) |
| header / footer | top / bottom of the screen |
| canvas | work area |
| scrubber | the bar you drag to move through a video |
| timeline | timeline (fine as is) |
| FAB (floating action button) | round "+" button that floats over the screen |
| kebab / overflow menu | "more" menu (three dots) |
| hover | point at with the mouse |
| tap / one-tap | tap / with one tap (fine) |
| gated / gates X | X is blocked until ... / only allowed after ... |
| surfaces X | shows X |
| roster | list of people |
| bulk | many at once |
| CRUD | create, edit and delete |
| metadata | details (date, owner, tags, and so on) |
| filter / facet | filter (fine) |
| drag and drop | drag (fine) |
| skeleton / spinner | loading placeholder / loading indicator |
| undo | undo (fine) |
| read-only | can view but not change |
| destructive action | action that deletes or can't be undone |
| draft | draft (fine) |
| state machine | the set of stages something goes through (e.g. ready, counting down, recording, stopped) |
| split view / two-pane | screen split into two side-by-side parts |
| dewarp (360 camera) | flatten the round 360° image into a normal view |
| preset (camera) | saved camera position |

## Abbreviations (spell out on first use per report)

| Short | First use |
|---|---|
| SRV | the session video review screen (SRV) |
| PTZ | remote-controlled cameras that pan, tilt and zoom (PTZ) |
| SP | standardized patient (SP) |
| SCE | Simulated Clinical Experience (SCE) |
| OSCE | objective structured clinical examination (OSCE) |
| LS | LearningSpace (just write LearningSpace) |
| LMS | learning management system (LMS) |
| SSO | single sign-on (SSO) |
| EMR | electronic medical record (EMR) |
| KPI | key performance indicator (KPI), or just "headline number" |
| GDPR | EU data-protection rules (GDPR) |
| OCR | automatic text reading from a photo or scan (OCR) |
| PO | purchase order (PO) |
| POS | point-of-sale (POS) |
| AV | audio and video (AV) |
| STT | speech-to-text (STT) |
| PTT | push-to-talk (PTT) |
| ICS | calendar file (ICS) |
| REC | the recording indicator ("REC" on screen); keep 'REC' when quoting the screen |
| UI / UX | the screens / the experience of using it |
| MVP | first version (MVP) |
| RSVP | reply to an invitation (RSVP) |
| OT | overtime (write "overtime") |
| NL | natural language, i.e. typed in everyday words (write it out) |

If a report uses an abbreviation not listed here and you are sure what it means, expand it the same way. If you are not sure, leave it and list it in your report.

## Added in Phase 2 (Courses and User management reports)

Research and report terms:

| Jargon | Plain |
|---|---|
| reference (a card on the page) | example |
| take | note (what we would take from the example) |
| synthesis | summary of findings |
| candidates / merged candidates | examples we looked at before choosing |
| curated / cut / narrowed | chosen / cut down |
| capture / sampled capture / preview | screenshot we collected |
| analogue / analogy / cross-domain | similar idea from a different kind of product |
| direct pattern | the same task, done in a real product |
| evidence | what the screenshots or documentation show |
| not established / not observed | the screenshots do not show it |
| fidelity | how complete or detailed it is |
| keeps (shortlist) | examples we kept |
| node (shortlist) | part of the User Manager (each of the six parts is one section) |
| provisioning / deprovisioning | creating / removing accounts automatically |
| attribute mapping | matching fields (name, email, role) between two systems |
| dry run | test run that shows what would change, without changing anything |
| directory | the university's central list of people and accounts |
| sync / directory sync | automatic copying of people and groups from another system |
| roster | list of people (for a course: the class list) |
| scoped to X / scope | limited to X / who or what it applies to |
| magic link | sign-in link sent by email, so no password is needed |
| escape hatch | a way to make an exception |
| time-boxed | open only for a set period |
| churn | keep changing |
| friction | extra steps that slow people down |

Abbreviations:

| Short | First use |
|---|---|

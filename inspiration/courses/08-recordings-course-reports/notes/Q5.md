# Q5 — Default metrics and cohort comparability

**Coverage:** Google Classroom ✗ (no report metric evidenced) · Mixpanel partial (engagement metrics and cohort breakdowns; no completion, attendance, score, or mastery).

**Google Classroom.** The capture is a Google for Education marketing page for Assignments. It says educators can distribute, analyze, and grade work and links to originality reports, but shows no report UI, default metric, learner result, cohort, or comparison (`refero:fb6de8d1-eec4-44ec-9a0c-5243aa683b90`). It therefore supplies product positioning only. Nothing visible establishes whether Classroom defaults to score, completion, attendance, or mastery.

**Mixpanel.** The evidence defaults to product-behavior measures. One retention view plots a weighted-average retention curve by elapsed day and opens a user panel for “<1 Day / Average,” showing two retained users (`mobbin:d8d5048b-159e-433d-a488-5a551f422bdf`). A second exposes the metric definition (“Retention Rate”), event pair, interval, and group basis; its tooltip reports 1.5 retained (75%) and 0.5 dropped (25%), with retained/dropped user actions (`mobbin:be374c47-a37d-4dd2-994f-d3ee89aed0e9`). The sampled drill flow is chart/table → tooltip → retained-user drawer (`mobbin:7b9ad250-9a11-47ad-87e0-9dab40727c2e`); the clicks between states and any individual profile are unobserved.

Comparability is more explicit in a separate report: named metrics, date range, country filter, device-type and cohort breakdowns, cohort-colored lines, and an average column (`mobbin:d7008305-0f24-4a04-8714-75d16b5284ff`). This supports like-for-like segmentation only when event definitions and filters remain stable. “Uniques,” events, activity, and retention are engagement proxies; they do not demonstrate attendance, course completion, assessment score, or competency mastery.

The export flow samples raw Events table → CSV/JSON modal with selected/all properties → changed selection → refreshed table (`mobbin:a8a15261-d74d-4f56-bf69-f19849059c12`). Modal-opening and export clicks, generated file, and cohort comparison after export are unobserved.

For course management, borrow visible metric definitions, shared filters, cohort breakdowns, and drill-down, while presenting completion, attendance, score, and mastery as separate outcome measures. **Candidate counter-example:** the Google Classroom reference, because marketing claims about grading provide no actual metric evidence.

**Best references:** `mobbin:d7008305-0f24-4a04-8714-75d16b5284ff` for explicit cohort breakdowns; `mobbin:be374c47-a37d-4dd2-994f-d3ee89aed0e9` for a defined retention metric and learner-list actions.

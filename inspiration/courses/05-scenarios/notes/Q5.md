# Q5 — Metadata carried into the outline

The strongest visible pattern is duration at two levels: a course-level total for planning commitment and per-activity estimates for scanning the outline. Mindvalley (`mobbin:99d3f73c-a804-4e4d-9b11-132afbe8ab1c`) shows the fullest learner sequence: Discover → program detail with 29 lessons, 11h 34m, and enrollment → Lessons with named items and minute estimates → a resource card labeled by type and 5-minute duration. This proves consistent display across learner views; it does not prove that metadata was copied automatically from a reusable library item.

MasterClass desktop (`mobbin:eeaba88c-51dc-44b0-8c15-cf8775b9c361`) and mobile (`mobbin:72dcf33e-58e8-486f-a178-583a2d411f67`) use progressive disclosure. Numbered section titles remain compact, while an expanded section exposes activity sequence, thumbnail, title, description on desktop, and duration where present. Udemy (`mobbin:987d1aea-1d31-4f63-ae58-5989ee6837c7`) uses a denser outline: section, lecture number, media type, title, remaining duration, and download action appear together. Both approaches keep timing close to the activity rather than in a separate detail view.

Teachable (`refero:screen-755d46c4`) is the counterexample. Its course-outline starting screen asks for course title and a student-facing description, then offers **Generate your outline**. No curriculum rows, durations, competencies, equipment, or metadata transfer are visible, so it supports contextual outline generation but provides no evidence for Q5’s carry-through behavior.

Across the five references, duration is the only requested metadata clearly shown in a finished outline. Mindvalley additionally shows aggregate lesson count, enrollment, and resource type. None establishes competencies or equipment in the outline, and none shows the authoring step that transfers metadata from a source scenario into a course instance.

# Q3 — Requirements / prerequisites

The strongest evidence shows two distinct kinds of enforcement. Kajabi lets an instructor **lock a module by a selected lesson** and explains that the module stays locked until that lesson is completed; an assessment lesson counts only when passed. This is explicit completion-order enforcement, communicated at configuration time (`mobbin:60f6d746-a953-49ba-9af9-784ff378d031`). Codecademy’s learner modal says course completion requires watching all content and scoring at least 70% on the test. That enforces completion/certification criteria, not entry to the course (`mobbin:6768ff06-2ec2-4e8b-8900-21500eb233a8`).

Skillshare is informational: the learner-facing detail panel labels the class “Beginner,” lists skills, and leaves “Watch Now” available. This is marketing-level/readiness guidance, with no observed prerequisite check (`mobbin:84584675-5845-46cc-a5bf-90fafdd128b4`). Uxcel similarly says “Beginner friendly” and describes who the path suits, then offers immediate enrollment confirmation. A separate Pro-membership upsell is a commercial access gate, not evidence of a learning prerequisite (`mobbin:074a824b-a9f4-4e59-9039-fc5a59eb12c4`).

Udemy gives authors a dedicated requirements/prerequisites text field in Intended learners. Its prompt asks for skills, experience, tools, or equipment learners should have beforehand; an example says no programming experience is needed. The page says these descriptions appear publicly on the course landing page. This supports authored informational readiness guidance, not enforced admission (`mobbin:4b041654-20d2-49dd-8779-2f45211103f7`).

**Sampled flow preview:** Podia’s five observed frames move from availability/sign-up limits and Publish, through curriculum and published audience/comments views. They show commercial/administrative access and publication state, not a prerequisite check or requirement gate (`mobbin:94f6be70-d9b2-4363-8091-62d20f8d1f9e`). Teachable’s single setup frame (step 1/5) contains title and description only, so prerequisite behavior is unknown (`refero:5f33c727-7dc2-479d-9000-e2728360224d`).

**Candidate counterexample:** Skillshare demonstrates useful readiness communication without enforcement: “Beginner” is visible at decision time while playback remains available.

**Gaps:** No evidence follows a learner failing Kajabi’s prerequisite, tests bypass/admin override, or shows whether Codecademy blocks certification versus later content. Udemy states where authored text will appear, but the learner-facing result and any runtime validation are not observed.

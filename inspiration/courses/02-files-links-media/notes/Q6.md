# Q6 — Learner-side view mirrors instructor-side structure

The evidence shows how learners encounter materials, but does **not** prove that any learner view mirrors its instructor editor. Parity requires both sides of the same course.

## Product answers

- **Coursera:** The learner shell separates checked **Course Material** modules from a **Resources** branch; the selected glossary opens with an external link and DOCX attachment ([mobbin:b3585969-4b16-4802-aea2-feaf40d75f33]). Mobile preserves Previous/Next sequence and places Transcript, Notes, Summary, and Attachments around media ([mobbin:d167e236-9aec-4856-8c79-27389df500a2]). No instructor screen establishes mirroring.
- **Skillshare:** The class page keeps the numbered video syllabus beside the player ([mobbin:ce6bd4c3-a5bf-4936-9052-271f2415fe4b]), while **Projects & Resources** is a separate top-level tab with project instructions and three download cards ([mobbin:bc678aba-07f0-4bbd-b48d-b4c5da47de0b]). Lesson-number references connect resources to progression without reproducing one visible hierarchy.
- **Podia:** Paired authoring evidence shows **Done/Publish**, editable module copy, linked resources, and a deletion toast ([mobbin:41f8b1f4-ec5f-4703-aeed-9b318eb0d5c0]). Its flow chooses **Add files** from **New lesson**, shows upload progress, then leaves the PDF among link and coaching items in the section ([mobbin:30a1432c-f8fd-4f5f-a026-53b0744635b2]). No learner counterpart is retained.
- **Teachable:** The Refero Q6 capture is an instructor editor: admin navigation, drag handles, **Publish**, **Edit**, and **Preview** surround lesson text and a DOCX resource in a sectioned outline ([refero:a68d25c8-7cda-41fb-aa23-67308245866e]). Paired screens confirm ordered sections and lesson publish states ([mobbin:f9d666fe-a496-450a-acb2-e9314ac4b4b8]) and PDF insertion inside a lesson ([mobbin:41a7198a-cb8b-4e01-8082-f4b6ddf7f73b]). No learner capture verifies Preview.
- **Udemy:** The learner **Downloads** tab retains a named section and numbered lecture list, with download controls per item ([mobbin:b9a7ca6e-c921-4ca5-9579-c18e634a7612]). No instructor-side pair establishes whether that structure is mirrored.
- **SuperHi:** A learner page separates **Links + downloads** from a numbered **Videos** list ([mobbin:f6e3fe92-3143-4fac-a11c-f3b178b9c6f4]); this suggests content-type grouping, with no instructor comparison.

## Distinctive difference and counterexample

Coursera distributes resources across lesson attachments and a separate library; Skillshare centralizes downloads under a project tab; SuperHi splits downloads from videos; Podia and Teachable embed resources directly in instructor sections. **Candidate counterexample:** Coursera’s separate Resources branch challenges a simple mirrored-tree model, although the missing instructor capture keeps this provisional.

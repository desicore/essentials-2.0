# Q2 — Organisation model

The evidence spans three models: course sections/modules, flat ordered lessons, and grouping by content type. None shows a general-purpose folder tree.

## Product answers

- **Kajabi:** The instructor outline nests lessons within modules and can add a Module, Submodule, Lesson, Quiz, or multiple videos ([mobbin:969eff25-d44e-41ee-94ea-498d216ae8ea]). Flow: open **Add content** → choose **Module** → enter title/description and optional image → **Create Module** → the new “User Testing” module appears at the outline bottom with its own **Add Content** and Draft control. This is the clearest hierarchical model.
- **Teachable:** The curriculum is divided into named sections containing ordered lessons. Each lesson row summarizes its material types and counts; section and lesson rows expose drag handles, menus, publish state, and section-level Drip controls ([mobbin:f9d666fe-a496-450a-acb2-e9314ac4b4b8]).
- **Podia:** A long instructor editor uses explicit module headings, then places lesson links, booking links, and a file directly beneath module copy ([mobbin:41f8b1f4-ec5f-4703-aeed-9b318eb0d5c0]). It supports section-tied mixed resources, although the screenshot does not expose the full outline.
- **Skillshare:** The learner player shows one flat numbered list of ten lessons beside the video, while **Projects & Resources** is a separate tab ([mobbin:ce6bd4c3-a5bf-4936-9052-271f2415fe4b]). No nested modules are visible.
- **SuperHi:** The learner page groups by medium: **Links + downloads** precedes a **Videos** section with numbered lessons ([mobbin:f6e3fe92-3143-4fac-a11c-f3b178b9c6f4]). This is type-based organization rather than a pedagogical hierarchy.
- **Coursera:** A mobile lesson is labelled “Lecture 1: BASIC PROGRAMMING CONCEPTS” and uses Previous/Next navigation; transcript, notes, summary, and attachments sit within the lesson ([mobbin:d167e236-9aec-4856-8c79-27389df500a2]). The wider course hierarchy is not visible.
- **Gumroad:** The selected **Content** tab shows a single freeform rich-text course page with formatting, links, files, page insertion, and a checklist ([refero:0286dd6d-2130-4b0c-b5f8-cb3cc7b78a0b]). **Receipt** is an adjacent inactive tab, so this is organization evidence rather than a receipt screen.

## Difference and counterexample

Kajabi explicitly supports two container depths; Teachable exposes one section depth; Podia embeds mixed items in module prose; Skillshare is flat; SuperHi groups by type. **Candidate counterexample:** Gumroad shows that a course can be one authored document without folders, modules, or lesson rows.

# Q1 — Upload, link, and embed entry points

**Podia** offers the clearest single entry point: in the course outline, open **New lesson** → choose **Add text**, **Add embed**, **Add quiz**, **Add coaching**, or **Add files**. The sampled file path then inserts an uploading `Case Study Guide.pdf` row in the same section and replaces progress/size with the completed file size. Types remain separate commands, but they share one menu and course context. [mobbin:30a1432c-f8fd-4f5f-a026-53b0744635b2]

**Teachable** uses a hybrid model. **Add content** opens a palette of distinct blocks: Text & Images, Video, PDF Viewer, Audio, Resource, Embed media, and others. For a PDF: **Add content** → **PDF Viewer** → choose a source. The dialog keeps local drag/drop, Google Drive, Dropbox, OneDrive, and URL in one place; sampled branches show entering a URL or selecting a cloud file and choosing **Upload**, after which the PDF renders inline in the lesson. This is the counterexample candidate: a unified launcher still requires users to choose a content-type feature before choosing the source. [mobbin:fc5a2e31-b68a-4560-adbd-64534e99d8c6] [mobbin:41a7198a-cb8b-4e01-8082-f4b6ddf7f73b]

A second nominal **Teachable** frame is a seven-step digital-product setup screen, not visibly a lesson editor. It directly contrasts **File upload** with **Redirect to URL**, but offers no embed option; retain only as a qualified analogue or relocate outside course authoring. [mobbin:38f8a761-116d-45ce-ad0c-b2d5f89c7e98]

**Dropbox Dash** has an **Add sources** modal where users can search or paste a file link, select an existing PDF, or choose **Upload**, then **Done**. This adds sources to Dash chat; it is not evidence of attaching course material. Keep as a generic unified-picker analogue. [mobbin:26e60a25-e5dd-4eff-aa2c-4ea33f1f9a2f]

**Gumroad** is a digital-product analogue. Its Content canvas combines rich-text/link controls, an **Insert** menu, and pages, but the closed menu does not prove file or embed options. [refero:11b3c0a4-eb09-4d98-9a1a-742439189540]

**Udemy** only shows a learner player's **Downloads** tab beside Lectures and More. It demonstrates consumption, not authoring; move to Q6 or exclude from Q1. [mobbin:b9a7ca6e-c921-4ca5-9579-c18e634a7612]

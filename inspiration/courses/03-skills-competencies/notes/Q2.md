# Q2 — Selection UX and scale

## Evidence by product

**Brilliant — short guided browse.** A learner chooses one of four broad domains, sees a selected outline, then continues. This flat list has no tree, search, suggestions, multiselect, or selected-set review. It suits a small onboarding choice but shows no mechanism for hundreds of competencies. **Corrected caption:** “Learner selects one of four onboarding domains.” [`refero:3345cd32-03fa-4571-9153-6ce930088570`]

**ClassDojo — compact class-skill management.** Edit Class > Skills shows Positive/Needs work categories, seven skill cards with point values, Add skill, Import from, and family-visibility choices. Browse and reuse are observed; search and hierarchy are absent. “Import from” may support scale, but its contents are not shown, so taxonomy selection is inferred. **Corrected caption:** “Teacher reviews, imports, or adds class skills.” [`mobbin:e102067a-a1a6-400a-81c4-626f7fbb066c`]

**Codecademy — progress browser, not selection.** A modal groups tracked subjects/languages under tabs, sorts them, visualizes XP, and expands “More available.” It supports scanning a growing catalog through grouping and sorting, but shows no selecting, search, suggestions, or course-authoring action. **Corrected caption:** “Learner browses skill progress and additional subjects.” [`mobbin:c3b8347d-6ee8-4087-8d92-7902f37a53d3`]

**Handshake — text-first accumulation and review.** The observed flow is profile Skills add → empty search-shaped field → enter text → convert it to a removable chip → accumulate several chips → Save and display a truncated set with “View all.” This is the clearest pattern for a large vocabulary: query-sized input avoids browsing hundreds, chips preserve selection state, and “View all” contains display growth. No suggestion menu or match list is visible, however; taxonomy-backed autocomplete remains an inference. Distinctive constraint: “We recommend 10 or less.” **Corrected caption:** “Enter and review profile skills as removable chips”; the original “suggestions” claim is unsupported. [`refero:8761`]

**Teachable — candidate counterexample.** The flow opens Curriculum, enters bulk edit, selects/renames section and lesson rows, and opens Drip settings. It demonstrates checkbox batch operations, drag handles, sections, and row actions for a long authored curriculum, but no reusable-item picker, tree, search, or competency selection. **Corrected caption:** “Bulk-edit authored curriculum rows and drip settings.” [`mobbin:78d51bc7-6260-4cde-a913-6fc1ccf11a26`]
